# 长截图滚动视口

2026-11-12

## 需求与结果

同一框选区域可以同时包含滚动正文、固定面板和工具栏。长图保持原框选宽度，固定区域只保留一次，新增高度中的对应位置留白。聊天成员栏只是用户提供的例子，不是应用或控件专用规则。

用户对 15:22 启动的版本实际复测后确认：**“固定区域只保留一次，正文完整”**。

## 边界来源

- 首次在原选区内滚动时，`LongShotSession` 取得滚轮事件的屏幕位置，后台调用 `ScrollRegionResolver` 查询该位置所属的最内层 `AXScrollArea`。
- 使用公开辅助功能接口读取角色、层级、位置、尺寸与滚动条几何；按父滚动区域、窗口和原选区裁剪。沿用既有辅助功能授权，不读取标题、正文或输入内容，也不操作目标应用。
- 不用 `AXContents` 的文字包围盒缩小正文。只有几何信息能证明滚动条独立位于内容外侧，才将其从拼接区域排除；覆盖在正文上的滚动条不能据此擦除正文像素。
- 无权限、没有可验证的滚动区域或查询超时时，在原选区上提示框选“会滚动的部分”，按回车确认；Esc 取消本次长截图。预览中的“滚动区域…”也可在实际拼接增长前打开此步骤。外层选区及其固定内容仍保留。
- 确定边界前仅保留最新待处理帧；屏幕点坐标按实际首帧像素尺寸换算为裁剪坐标。

## 拼接与固定区域

`FrameStitcher.setScrollingRect` 配置滚动区域。只在该区域内沿用相邻原始帧位移匹配与局部悬浮控件接缝处理，不再用静止列、成员图标、列表行或分隔线外观猜测固定区。

输出在原横向位置扩展正文：顶部与左右固定区域取首帧且只绘制一次，新增高度的左右部分填白；底部固定区域取最近一次成功增长帧并放在结果末尾。局部悬浮控件仍交由视口内的重叠帧接缝处理，不将其所在整列涂白。总输出保留 6,400 万像素上限。

一次长截图处理一个主要纵向滚动视口。开始增长后不可更换视口；如果在原选区内改滚另一个区域，会结束并保留当前结果。系统未暴露准确几何的界面需要手动指定滚动区域；该路径不等于自动分割任意二维固定面板。
