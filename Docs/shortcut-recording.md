# 快捷键录制（2026-11-12）

## 原因与实现

设置里的“录制”按钮原来只有 TODO 和“尚未实现”提示；全局注册已能观察配置更新，但缺少按键录入与验证入口。

设置现在与启动时共用 `AppEnvironment.shortcutCenter`。录制一行时释放现有全局注册，接收修饰键及主键并即时展示；主键抬起后验证、保存、恢复全局注册。录制期间及旧注册的排队回调不会执行截图等动作。

- 点击“录制”后按组合键，松开主键自动保存。
- Esc 取消，Delete / 向前删除清除；也有“清除”按钮。
- 允许 Command、Control、Option 搭配其他键，也允许单独 F1–F20。Shift 可以叠加，普通字母或仅 Shift 加字母不作为全局绑定。
- 内部重复绑定显示冲突动作；系统保留或拒绝的组合显示具体原因。试注册失败保留原绑定，继续等待新输入。
- 窗口关闭、失去焦点、切换设置页时取消录制并恢复原绑定；切换录制行丢弃前一行未完成的输入。
- “恢复默认快捷键”只修改快捷键，不重置截图输出、录屏帧率、标注或主题设置。
- 注册仍沿用现有冲突优先响应策略，不更改 Ctrl+1 的行为。

已有辅助功能授权时，录制使用短期 session event tap，避免已被其他应用占用的 Ctrl+1 在录制时被抢走。它仅在设置窗口为当前活动窗口且一行正在录制时消费键盘事件；结束即释放，不记录输入文本。未授权时退回应用内事件监听，不主动请求新权限；其他应用已拦截的按键可能无法到达该后备入口。
