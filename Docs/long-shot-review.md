# 长截图问题梳理与修复

日期：2026-11-11。范围：macOS 屏幕选区的手动向下滚动截图、实时预览、结果查看与导出。

## 已定位的问题

| 问题 | 证据与原因 | 本次处理 |
| --- | --- | --- |
| 完成、取消按钮被提示文字挡住 | 260 点宽的面板里，160 点提示与右侧按钮区域相交；AppKit 回归已复现 | 状态、滚动图像、操作栏分别布局；操作栏始终固定 |
| 小屏面板越界，避让位置不正确 | 固定窗口尺寸未约束到可用屏幕；选区和窗口分别使用左上、左下原点 | 包含标题栏的整个窗口限制在屏幕内；先转换坐标再避让 |
| 长图缩成细条、无法查看文字 | 原来按宽高同时适配整张图，代码注释说可滚动，但并无滚动容器 | 使用 NSScrollView；默认适宽，支持原始像素、横纵滚动和结果窗口缩放 |
| Retina 选区不完整甚至为空 | SCDisplay 尺寸是点，旧流输出未乘显示比例，裁剪却乘了 scale；右下角回归裁成 nil | 首屏与流均输出原始像素；流裁剪读取实际帧比例 |
| 自动吸附后立即结束 | 小数选区首屏四舍五入、流向下取整；案例分别为 401×301 与 400×300 | 首屏与流统一对齐到像素网格；过小选区明确要求重选 |
| 第三帧起重复内容或失败 | 累计长图被当成上一屏；四帧案例第三张应为 500 行却变成 600 行 | 单独保存上一张接受的原始帧，累计图仅用于输出 |
| 接缝少行、微小滚动丢失 | 原来纵向也降采样，1300 像素宽案例滚动 137 行后结果少一行 | 仅压缩横向匹配样本，保留原始像素行；允许 1 像素有效位移 |
| 固定底栏、空白内容影响匹配 | 单个底部模板容易命中固定栏；完全静止的空白帧也被判失败 | 比较整个重叠区，排除两帧共同静止边缘；替换旧底栏；相同帧不重复追加 |
| 拼接失败没有反馈 | try? 静默丢弃失败帧 | 显示未拼接和恢复操作提示；反向滚动单独提示；保留最后有效结果 |
| 自身窗口可能进入截图 | 只设置 window.sharingType，流过滤器没有排除自身 | 首屏与后续流均使用 excludingApplications |
| 取消、快速重启产生异步串扰 | 启动、停止和排队处理缺少会话隔离 | 流与长截图会话各自核对会话标识；停止后旧回调不改新状态 |
| 操作入口丢失后不易找回 | 再次触发入口可能发起新的框选 | 再次选择长截图或按已配置快捷键，将当前面板前置 |

## 技术资料与采用的方法

1. [Richard Szeliski：Image Alignment and Stitching: A Tutorial](https://www.microsoft.com/en-us/research/publication/image-alignment-and-stitching-a-tutorial/)，微软研究院技术报告，PDF 最后更新于 2006-12-10。[原文 PDF](https://www.microsoft.com/en-us/research/wp-content/uploads/2004/10/tr-2004-92.pdf)。重点是运动模型、直接像素对齐、误差度量与重影问题。这里据此选择受约束的竖直平移；界面文字不需要照片全景的透视形变或接缝混合，合成直接复制原始像素条带。这是针对本项目的工程取舍。
2. [OpenCV 官方 Template Matching](https://docs.opencv.org/4.x/de/da9/tutorial_template_matching.html)。参考归一化互相关的匹配原理；本项目自行实现，并未引入 OpenCV 依赖。候选位移遍历后检查独立次峰，再验证完整重叠区，避免相似列表被强行拼接。
3. [Apple 官方 Capturing screen content in macOS](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos)。采用其屏幕点数乘显示比例、应用过滤和完整帧检查方式；新增启动/中断错误反馈。[WWDC22 Meet ScreenCaptureKit](https://developer.apple.com/videos/play/wwdc2022/10156/)说明了内容过滤与流配置机制。

## 交互行为

- 截取中：可拖动面板，完成/取消一直在底部；新内容自动跟到底部，用户向上回看时不强制跳回。
- 未匹配：保留已有长图，提示回滚少许、恢复重叠后再慢慢向下滚动。
- 完成后：适宽阅读；切换原始像素检查文字和接缝。一图像像素对应一个物理屏幕像素，Retina 下也一致。
- 复制、保存后保留结果窗口；关闭结束会话，贴图后交给贴图功能。
- 再次触发长截图入口可找回当前预览，避免误开新会话覆盖结果。
- 捕获最多处理一张在途拼接帧，防止后台积压；输出限制为 6400 万像素，达到上限时保留已有结果。

## 验证与边界

自动回归覆盖多帧逐像素比对、Retina 奇数位移、CoreText 稀疏文字、规则重复列表、固定头尾、静止空白、小位移、反向滚动后恢复、帧尺寸变化，以及真实 AppKit 布局、滚动与原始像素模式。屏幕配置和取消启动竞态使用可控输入测试，不等同于跨设备实测。

最终整包测试：**76 项通过，0 失败**，约 7.8 秒。其中拼接 13 项、预览 7 项、屏幕流 4 项、小数选区一致性 1 项。测试输出保存在 `/tmp/sensnap-longshot-tests.log`。Release 构建及项目现有本地证书签名完成，产物为 `dist/SenSnap.app`；旧安装包备份为 `/tmp/SenSnap-before-longshot.zip`。

性能实测使用 CoreText 合成文字、1600×1200 像素视口、6 次各 137 像素位移：Release 单次 append 为 27.8–40.4 毫秒，包含匹配和合成，不含采集、预览和编码，不代表所有网页表现。

完整交互验证尚未完成：本地 HTML 的 file URL 被浏览器工具策略拒绝，改用公开 OpenCV 文档后，网页与应用控制多次超时。应用已启动，未更改系统权限。不能据此声称浏览器连续抓取、真实多屏、窗口排除与保存链路已全部通过。

可重复的人工场景见 [本地回归页](../Tests/Fixtures/LongShot/scroll-page.html)：连续 24 段编号、不同段落高度、固定标题栏与结束标记。分别选正文和含固定栏的区域，检查编号连续性、接缝、窗口排除、复制保存后的预览、再次触发入口和取消。

仍有明确边界：只向下延伸，不实现向上扩图或水平拼接；高速跨越无重叠内容、完全重复列表、动态视频/动画、大面积固定侧栏、改变高度的吸顶栏，可能无法可靠匹配。失败时保留结果并提示，不保证这些页面都能无缝拼接。共同静止边缘检测并非通用的固定元素语义识别。

本次没有引入自动滚动、浏览器 DOM 全页截图、OCR 拼接或图像生成修补，以保持通用桌面选区行为和原始文字像素。
