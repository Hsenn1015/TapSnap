## 修复内容

- 普通截图默认改为 ⌘1，配置版本升级到 3。只迁移旧版发放的 ⌘⇧1；保留自定义、取消绑定与其他动作已占用的组合。菜单从配置自动同步。
- 热键注册与事件处理器均使用 dispatcher target。诊断版已收到系统 subtype 6 事件并执行截图、长截图启动动作；移除临时事件监控，保留正常动作日志。
- 长截图默认组合由 ⌘⇧3 调整为 ⌘⇧L。当前系统的 `CopySymbolicHotKeys` 确认 ⌘⇧3 已启用为系统热键；Apple 也将它列为[全屏截图组合键](https://support.apple.com/en-ie/102646)。配置版本升级到 2，只迁移旧版的这项默认；其他自定义组合、用户已取消的绑定均保留。如果 L 已被其他自定义动作使用，不自动制造新冲突。
- 注册前检查当前启用的系统组合；使用 `kEventHotKeyExclusive` 注册。系统或其他应用占用时明确失败，菜单仍能点击启动。Apple SDK 的 `CarbonEvents.h` 明确：普通非独占注册在有独占占用者时仍可返回成功，但不会收到通知。
- 快捷键配置改变后立即差量重注册，删除绑定立即注销；修改其他设置不重注册。支持两个动作交换组合，拒绝同应用重复绑定并显示提示。
- 菜单快捷键来自实际配置，不再硬编码；登记失败标注不可用及原因。
- 注册表改为弱引用，释放快捷键对象时可以正常注销；事件处理器只缓存安装成功的引用，失败可重试。
- 修正 macOS 物理数字键码与显示字符的对应关系，避免 5、6、7、8、9、等号显示错键。
