## 极简分块翻译卡、秒译流式提速、设置精简与 Windows 全功能同步

这一版本为「截图秒译」新增第 5 套默认风格「极简分块卡片」并保留全部原有 4 套风格，全面优化 Google 翻译与大模型首译速度与实时流式输出，支持浮卡内即时切换翻译引擎与设置页查看/复制已保存密钥，精简全部设置页冗余说明小字，并将近期全部核心能力完整同步至 Windows 版。

### 截图秒译体验全面升级（macOS & Windows）

- **全新默认风格「极简分块卡片」**：采用四区 Bento 分块布局（可拖动置顶与动作顶栏 + 原文块支持朗读/复制/自动语种识别/原地改字重译 + 对称语言互换条 + 译文块），同时完整保留 **液态玻璃语义胶囊**、**聚光取词取景器**、**原地双语高亮卡** 与 **灵动岛气泡卡** 共 5 套风格随时切换。
- **浮卡内即时切换翻译引擎**：无需等待超时或重新框选，在任意秒译浮卡风格中点击当前引擎名即可随时切换 Google / 百度 / DeepL / 微软 / 腾讯 / 有道 / 本机模型 / 在线大模型（DeepSeek / 通义千问 / 自定义）或打开设置。
- **首译提速与大模型 SSE 流式输出**：关闭代理环境下易卡顿的 HTTP/3 QUIC 探测，增加启动/保存/框选期 DNS+TLS 连接预热与 128 条内存译文缓存；在线与本机大模型全面接入 SSE 逐词流式输出，显著消除首字等待。
- **修复原文区排版溢出与窄框滚动**：重构分块卡片自适应高度逻辑，长段原文可在充裕视口内平滑滚动，不再遮挡底部操作栏或语言互换条。

### 设置页全面精简与密钥可查（macOS & Windows）

- **已保存 API Key 可查看与一键复制**：设置页打开或切换服务商时自动回填已保存密钥，保存后不再自动清空，支持小眼睛明文切换与一键复制；同时修复了翻译服务分段选择控件文字截断问题。
- **移除各分页冗余小字**：精简「通用」「截图」「截图翻译」「隐私打码」「贴图」「录屏」「长截图」「快捷键」「自定义工具栏」等页面的冗余说明文字与冗长副标题，必要提示收纳至悬停提示中，界面更清爽紧凑。

### Windows 版全功能同步

- **统一翻译引擎与截图秒译**：同步 6 家第三方翻译 API、大模型 SSE 流式输出、连接预热、DPAPI 加密密钥存储与 5 套风格「截图秒译」（支持全局快捷键 `Ctrl+Shift+T` 松手即译与 `Tab` 切语言），并在主设置窗口新增独立「截图翻译」分页。
- **7 大选区边框、6 款贴图阴影、原位贴图与演示模式**：同步 7 大边框家族（含动态效果与多套主题配色）、6 款贴图阴影（含自适应取色溢光、磨砂玻璃画框、右键快切样式与浓淡/扩散调节）、截图原位贴图以及「演示模式（允许录屏）」。
- **19 款录屏鼠标动效与 GIF 倍速**：同步 14 款点击动效 + 5 款滚轮动效（通过低级鼠标滚轮钩子捕获）+ 5 组配色与可交互预览区，录屏预览 GIF 导出新增 `0.25×`–`4×` 倍速选择。
