在 Mac 上按 `⌘⇧1` 开始截图，框选后按 `⌘T`，图片会直接贴在原选区上。松开鼠标就能看清位置，按住图片即可拖走。

## 贴图体验

- **修复贴图跳到屏幕右上角。** 框选后直接贴图会保留选区的位置和显示大小。在编辑器里标注或裁剪后再贴，也会对准原图中对应的位置。支持 Retina 和跨显示器选区。
- **修复贴图前短暂闪动。** 贴图首帧就绪后才收起框选层、编辑器或长截图预览。取消了贴图时的等待和弹出动画，已有贴图的前后顺序也会保留。
- **截图预览与结果一致。** 框选视频或动画时，选区内显示实际截取的那一帧，贴上去时画面不会突然跳回。滚动截图和录屏的选区仍显示实时内容。
- **从剪贴板恢复位置。** 用 `⌘⇧V` 贴出由 TapSnap 复制的截图，会保留位置和显示大小。已经拖动过的贴图会记住新位置，从其他应用复制的图片则放在鼠标附近。

## Mac 默认快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 区域截图 | `⌘⇧1`，原为 `⌃1` |
| 框选或编辑后贴图 | `⌘T`，原为 `Shift+P` |
| 直接进入「截图并贴图」 | `⌘⇧2` |
| 将剪贴板图片贴到屏幕 | `⌘⇧V` |

`⌘T` 只在 TapSnap 框选或编辑时使用，在浏览器或终端里仍可新建标签页。升级时会迁移旧默认值，保留其他自定义和已清除的键位；如果新组合已分配给别的动作，会保留原绑定。可以在「设置 → 快捷键」中调整。

## 下载与升级

Mac 版支持 macOS 14 及以上的 Apple 芯片机型。选择 `.pkg` 安装向导，或打开 `.dmg` 将 TapSnap 拖入「应用程序」。本版沿用 v0.2.8 的固定发布签名，尚未经过 Apple 公证。

Windows 版提供 x64 和 ARM64 的安装向导与便携 ZIP。上述贴图和快捷键改动适用于 macOS。
