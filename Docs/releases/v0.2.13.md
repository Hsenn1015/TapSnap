## macOS 截图秒译、液态玻璃编辑台、录屏鼠标动效与长截图全面升级

这一版本新增零跳转「截图秒译」悬停浮卡、重构录屏与长截图编辑工作台为液态玻璃浮岛风格，带来 19 款录屏鼠标与滚轮动效，并大幅提升长截图在存在固定侧边栏/底栏时的拼接准确度与实时预览流畅度。

### 全新「截图秒译」悬停浮卡（4 套风格 × 松手即译）

- **专属框选视觉与松手即译**：通过状态栏「截图秒译」或自定义全局快捷键进入，光标旁实时显示目标语言提示牌，拖拽框选松手即刻弹出译文浮卡，无需二次确认、不跳大窗；框选期间按 `Tab` 可快速切换目标语言（简体中文 / 英语 / 日语 / 韩语）。
- **4 套原生浮卡风格自由切换**：内置 **液态玻璃语义胶囊**（默认）、**聚光取词取景器**（零顶栏首行直出译文）、**原地双语高亮卡**（支持「仅译文 / 双语对照 / 覆盖原文」三态切换，覆盖原文可自动滑移至原文字正上方）与 **灵动岛气泡卡**（加载胶囊弹簧展开为译文气泡 + 外侧竖排动作豆子），浮卡内点 ✨ 或在「设置 → 截图翻译」均可随时切换。
- **内容自适应尺寸 + 自由拖拽与缩放**：按单词/句子/长段及当前字号自动计算最舒适的列宽与高度；四条边与四个角均支持零抖动拖拽缩放，双击角落或点击复位按钮可一键恢复自适应；卡片顶部手柄与空白区支持 1:1 丝滑拖动，圆角遮罩毛玻璃搭配柔和悬浮阴影。
- **自定义文本样式与无缝接力**：浮卡内置 `Aa` 排版弹窗，支持自定义字体（系统 / 衬线 / 圆体 / 等宽）、译文与原文字号、段落行距及 6 组强调色并自动持久化；英文单词/短词自动附带 macOS 本地词典音标与词性；一键「展开大窗」可直接复用本次 OCR 结果进入完整翻译窗口。

### 录屏与长截图编辑台液态玻璃重构 + GIF 倍速 + 拖出发送

- **液态玻璃浮岛布局**：全面重绘录屏预览与长截图预览编辑台，升级为柔和渐变画布搭配通透毛玻璃顶栏、底部动作浮岛与分段切换胶囊，交互反馈更顺滑。
- **GIF 导出倍速调节**：录屏预览支持 `0.25×`–`4×` GIF 导出速度调节，方便快速压缩长演示或放慢操作细节。
- **原生拖出发送**：支持从编辑台直接拖出 MP4 / GIF / 长图文件（基于 `NSFilePromiseProvider`）投递到微信、飞书、Slack、备忘录或访达，无需先保存再找文件。

### 14 款录屏鼠标点击动效 + 5 款滚轮动效 + 5 组配色

- **14 款点击动效与 5 款滚轮动效**：在「设置 → 录屏」新增涵盖液态玻璃水波、方框角标轻扣、精密靶环合焦、轨道一笔画弧、声呐三连波、键帽微章等 14 款点击动效与 5 款滚轮滑动视觉反馈，搭配 5 组左右键配色方案、尺寸倍率滑块与明暗双底实时动态预览。

### 长截图静态区域识别与实时预览流畅度升级

- **固定侧边栏/底栏自动分离**：引入基于运动掩码的固定左右侧栏自动识别与闪烁光标/时钟页眉页脚裁切，同时优化可滚动区域优先匹配，显著减少手动调整框选区域的频率。
- **更流畅的 30fps 实时预览**：升级为 4× 垂直金字塔由粗到精位移搜索、O(1) 脏区切片绘制、缓存缩略导航图与最新帧合并策略，大幅消除小视图预览卡顿。
