如果 TapSnap 在系统设置里已经获准录屏，打开时却反复提示缺权限，升级后可以在菜单栏点击「权限检查」重新检测。从上个公开版本 0.2.5 升级，还可以使用自定义框选工具栏和 OCR 原图对照。

## 新增功能

- **自定义框选工具栏（macOS、Windows）**　在截图设置中打开「框选工具栏 → 自定义…」，可以选择框选后直接显示的按钮、调整顺序，并将低频操作收进「更多」。保存后，下次截图会沿用这套布局。
- **OCR 原图对照（macOS、Windows）**　识别结果与截图原图并排显示。搜索关键词后，可逐行或逐段复制，或点击定位按钮，在原图上核对该段文字。两个平台都支持查看 Markdown 预览和编辑源码。

## 问题修复

- **macOS 录屏权限误报**　「权限检查」现在由正在运行的 TapSnap 检测能否访问屏幕。系统拒绝访问时才显示授权引导，其他采集错误会显示相应原因。已允许录屏、只缺少可选的辅助功能权限时，窗口会明确显示「可以截图和录屏」，点「完成」即可。权限生效后可继续刚才的截图操作，录屏授权中断时会保留原显示器和选区。
- **macOS 权限提示截断或消失过快**　引导窗口会按内容调整高度，在小屏幕上可滚动阅读，切到系统设置时仍会保留。从引导打开系统设置、允许录屏后，切回 TapSnap 会自动复查；授权生效就接着刚才的操作。若系统仍未放行，窗口会保留检测结果，并提供手动复查和重新打开应用的入口。
- **macOS 启动时的快捷键警告**　可选的快捷键优先响应缺少辅助功能授权时，启动过程不再重复弹出长提示。其他快捷键冲突会显示 6 秒摘要，完整原因可随时在「设置 → 快捷键」查看。授权生效后会重试注册失败的快捷键。
- **截图标注误选（macOS、Windows）**　在斜箭头旁边或空心形状内部画新标注时，旧标注有时会被意外拖走。现在可以在这些空白处正常起笔，点击箭杆、箭头或形状轮廓仍可选中原标注。
- **macOS 滚动长截图**　系统识别不到滚动区域时，可在最初框选的范围内继续手动拼接。滚动区域锁定后，触控板惯性滚动时短暂移出正文也不会提前结束截图。
- **Windows 录屏控制条**　修复高缩放比例及多显示器环境中录屏控制条可能出现在屏幕边缘外的问题。框选确认按钮和录制控制条会按录制所在显示器的工作区布局。
