## macOS 原生流体设置页、全应用编辑快捷键与 Qwen-MT 翻译修复

这一版本全面重塑了 macOS 设置窗口的视觉与交互体验，补齐了纯菜单栏应用缺失的系统编辑快捷键（`⌘A / ⌘C / ⌘V / ⌘X / ⌘Z`），并原生兼容阿里云百炼 `qwen-mt-*` 系列专用翻译模型及真实报错透出。

### macOS 设置界面视觉与交互升级

- **原生流体窗口与毛玻璃侧边栏**：启用一体化透明顶栏（`fullSizeContentView`）与可拖拽顶部区域，侧边栏采用 macOS 原生毛玻璃材质与彩色圆角图标徽章，按「基础 / 截图 / 录屏 / 智能」分组并支持 `⌘1`–`⌘9` 快速切换；窗口支持自由缩放并自动记住位置与上次停留分类。
- **统一的视觉层次与控件质感**：浅色采用柔和冷灰画布 + 浮起纯白卡片，深色采用深炭画布 + 绸面卡片；主按钮、开关、滑块、选中态与输入框聚焦光环统一为 macOS 系统蓝，表单输入框加宽加高，长 API 地址与密钥展示更清晰。
- **交互细节打磨**：
  - **滑块步进与延迟落盘**：拖动滑块时只在内存实时更新预览，松手后落盘一次，避免每帧写盘与浮点小数偏移，并补全键盘方向键与 VoiceOver 无障碍支持。
  - **保存逻辑一致化**：「截图翻译」默认目标语言与 Apple 离线翻译即改即生效，未保存的服务/密钥改动显示明确「未保存」标识；「隐私打码」切回「仅本机规则」时保留已填写的服务商地址与模型配置；破坏性操作（恢复默认快捷键、关闭全部贴图、删除自定义规则、移除已存密钥）均增加二次确认。
  - **页面体验统一**：重构「长截图」页为统一卡片风格并新增慢/标/快速度预设；快捷键支持直接点击键帽录制且反馈就地显示在当前行；移除边框/动效配色的重复下拉框；录屏页补全摄像头/麦克风/系统声音缺权限时的行内授权入口。

### 全应用输入框快捷键与 Qwen 翻译修复

- **修复所有输入框无法使用系统快捷键**：为 `.accessory` 菜单栏应用注册标准 `NSApp.mainMenu`（「编辑」与「窗口」菜单），恢复设置页、翻译弹窗、隐私规则、取色器及标注文字编辑中的 `⌘A` 全选、`⌘C` 复制、`⌘V` 粘贴、`⌘X` 剪切、`⌘Z` / `⇧⌘Z` 撤销重做与 `⌘W` 关闭窗口。
- **原生适配 `qwen-mt-*` 专用翻译模型**：自动识别 `qwen-mt-plus` / `qwen-mt-turbo` / `qwen-mt-flash` / `qwen-mt-lite` 等模型，改用百炼要求的单条 `user` 消息 + `translation_options`（完整英文语种名）请求体，不再发送被拒的 `system` 提示词与 `enable_thinking`，并兼容 `qwen-mt-plus` 流式累计块去重。
- **透出真实服务端报错**：模型服务返回非 200 状态码时自动解析并展示服务端 `error.message`，排查模型名称、密钥或配额问题更直接。

## 下载与升级

- **macOS（Apple 芯片）**：使用 v0.2.14 的用户可在菜单栏选择「检查更新…」，或下载 `.pkg` 安装向导 / `.dmg` 镜像。
- **Windows（x64 / ARM64）**：下载对应架构的 `-Setup.exe` 安装向导或便携版 `.zip`（内置完整 .NET 运行时，开箱即用）。
