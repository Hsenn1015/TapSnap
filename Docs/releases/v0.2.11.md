## macOS 截图翻译全面升级

重构了 macOS 截图翻译的窗口、交互流与翻译引擎，提供更快的响应速度与更清爽的阅读整理体验。

### 界面与双模式体验

- **全新无框悬浮窗**：与 OCR 面板保持统一设计语言，支持窗口置顶切换、一键再截一张、自定义语言互换与自适应窗口尺寸。
- **「对照」模式**：左原图、右译文双栏展示，支持**拖动中间滑块自由调节左右比例**（双击恢复默认并自动记住）；右侧支持「译文 / 对照」视图切换、原图与译文双向高亮联动、以及行内润色译文或改原文重译。
- **「原图」模式（原位覆译 + 划词翻译）**：
  - **原位覆译**：自动采样原图文本块背景色，将译文自然融合贴回原图对应位置，按住 `Space` 键可随时透视原图对比。
  - **划词翻译**：默认纯净划词不抢跑，可选开启「悬停译」；译文浮卡支持自由拖动位置、右下角拉伸大小、图钉固定（移开不消失且继续点读刷新）以及就地样式调整。

### 多选整理、智能滤杂与自定义样式

- **批量清理杂文**：右侧新增「整理」模式（也可按住 `⌘` 点击段落快速进入），支持 `Shift` 连续连选、**删除所选**、**仅保留所选**、**一键清空**，并支持整批事务 `⌘Z` 撤销恢复。
- **智能选中杂项**：一键自动预选截图中的纯符号、数字页码、百分比、时间戳与状态条等冗余碎片，核对后一键删净。
- **排版与高亮样式 (`Aa`)**：可实时调节原文字号、译文字号、字体风格（系统 / 衬线 / 圆体 / 等宽）、行距及 6 种高亮强调色，并全局同步至对照卡片、浮卡与原图高亮框。

### 接入 6 家高速第三方翻译 API 与按需翻译

- **新增「翻译 API」通道**：支持 **Google 翻译**（免 Key 快捷通道 + 官方 Cloud API v2 及反代）、**百度翻译**、**DeepL**（自动识别 Free / Pro）、**微软翻译 (Azure)**、**腾讯翻译君 (TMT)** 与 **有道翻译**，支持整图单次批量请求与试译测速；所有密钥继续保存在本机独立 `0600` 权限文件中，不写入普通设置。
- **打开后自动翻译开关**：支持关闭自动翻译，打开后先做免费本机 OCR，清理杂项或勾选正文后再手动翻译所选/全部段落，避免浪费 API 额度。

## 开发者体验

- `Scripts/build-app.sh debug` 支持打包 `dist/dev/TapSnap 开发版.app`，独立存储设置和历史，可与正式版同时运行调试。

## 下载与升级

使用 v0.2.10 的 Mac 用户可以在 TapSnap 菜单栏选择「检查更新…」。也可以下载 Apple 芯片版 `.pkg` 安装向导，或打开 `.dmg` 将 TapSnap 拖入「应用程序」。
