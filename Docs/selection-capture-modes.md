# 框选后切换长截图与录屏（2026-11-12）

普通截图（Ctrl+1、菜单或悬浮球）完成框选后，选区工具栏提供“长截图”“录屏”和“截图 ⏎”。点击直接使用当前选区；移动或拖动手柄调整后的结果同样生效，不再要求第二次框选。Enter、双击继续确认普通截图，Esc 取消。

工具栏仅在松开有效选区后显示，放在选区外侧并限制在屏幕可见范围。按钮之间的留白不穿透为新的选区。专用 OCR、贴图、长截图滚动区域等框选仍保留原来的确认/取消行为。

## 交接流程

- 三种方式共用 `ScreenshotSession.select(viewRect:on:)`：视图左下原点转换为屏幕全局左上原点。长截图使用全局坐标，录屏使用该显示屏内的局部坐标，保持 Retina 和负屏幕原点下的实际选区一致。
- 普通截图切换长截图时，关闭覆盖层后按原显示屏重新抓取排除 TapSnap 窗口的首帧，匹配长截图流的排除规则，再使用原选区裁切。不会直接把可能包含本应用窗口的普通截图缓存交给长截图。
- 初次抓屏及切换长截图的异步结果都检查会话 UUID；取消后的旧结果不能重开覆盖层或进入另一个会话。
- 录屏直接使用已有选区进入原录制控制条与预览流程。旧预览先关闭；已有录制任务时显示原控制条并提示，不启动第二个录制任务，也不结束原任务。
