## 翻译与公式的准备要求

翻译入口包括菜单「截图翻译」、编辑器更多菜单和指南。调用链为 `CaptureCoordinator(.translate)` / `EditController.perform(.translate)` → `AppEnvironment.translateImage` → Vision OCR → `TranslationPanel`。用户选择源语言和目标语言后调用系统 `translate()`，由系统按文本识别源语言并准备语言包；需要 macOS 15 或更新版本，首次使用可能由系统提示下载语言包。正文在设备端处理。

公式入口包括菜单「公式识别」、编辑器更多菜单和指南。调用链为 `CaptureCoordinator(.formula)` / `EditController.perform(.formula)` → `FormulaPanel` → `LocalFormulaRecognizer` → 包内 `formula_recognize.py`。运行环境位于 `~/Library/Application Support/com.sensnap.app/formula-runtime`，使用 pix2tex；每次请求启动独立进程，完成或取消后退出，模型不会常驻主应用。

首次准备需要 Python 3.12、将应用安装到 `/Applications/TapSnap.app`，并运行发布目录的 `Install Formula.command`。安装器下载依赖与模型并校验模型文件；本机运行环境已安装且通过离线识别与权重校验，约占 **1.2 GiB 磁盘**。识别脚本禁用网络连接；KaTeX 脚本、字体与样式随应用打包，LaTeX 修改后本地同步预览，可复制 LaTeX 或预览图片。未准备运行环境时应用明确显示安装提示。

WebP 编码由随主程序静态链接的 libwebp 提供，发布包不依赖机器上的 `cwebp` 或 Homebrew 动态库。模型运行环境与 WebP 的打包方式不同，不能把公式 Python 环境描述为主程序自包含内容。

## 本地历史边界

- 活动贴图最多 40 张、最近关闭最多 20 张，合计解码内容预算 512 MiB；超过预算优先移除较旧关闭记录，再移除较旧活动项。超过预算的单张贴图仍可显示，但不写入重启恢复历史。
- 剪贴板最多 50 条、128 MiB 解码内容，单条文字最多 20,000 字符；不采集来源标记为私密或临时的内容。
- 图片文件与清单位于应用自己的本机支持目录；清空历史只删除该历史类别中的记录，活动贴图不受「清空关闭记录」影响。
- 鼠标穿透后不需要点中原图即可恢复：菜单「贴图分组」仍可打开，其每张图片行都有恢复操作。全屏自动隐藏开关也位于这个独立面板，退出全屏自动恢复时仍尊重用户主动隐藏的分组。
