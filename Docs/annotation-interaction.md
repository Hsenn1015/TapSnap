# 标注实时预览与序号落点

2026-11-12

拖动预览原来统一绘制系统强调色的虚线矩形（画笔则是虚线路径），未调用实际图元的绘制逻辑；序号工厂把点击点作为 22×22 图元的左上角，视觉中心偏移 11 点。新一笔也没有初始化终点，会沿用上一笔的坐标。

改动：

- 草稿与提交使用同一构造入口，草稿调用真实 `prepare`/`draw`，使用当前颜色、线宽和底图。草稿不加入文档、撤销栈或导出；文字尚未输入时保留其占位框。
- 释放时取最终鼠标位置；开始新笔重置终点，Esc 或切换工具取消未完成草稿。
- 序号工厂以点击点为中心，可直接单击放置，也可按住移动后在释放点放置。当前工具为序号时优先盖章，避免鼠标显示下一数字却误拖已有标注。
- 使用真正的 NSCursor 显示下一枚数字图标，热点是中心；随颜色、显示缩放、添加/删除/撤销/重做更新。只在画布的光标区域生效，不使用全局隐藏鼠标，不将悬停预览写入图片。
- 下一序号取现有最大编号加一，避免删除中间数字后重复。
- 多边形预览使用真实线条/填充，并跟随鼠标展示下一段。

验证：

- 修改前，箭头/椭圆拖动预览与真实图元的像素对照失败；序号中心偏移、删除中间序号后重复也通过测试复现。
- 0.5、1、2 倍显示缩放下，箭头/椭圆草稿与实际图元、提交后的图像逐像素一致，草稿期间文档为空。
- 序号直接单击、原点单击、拖后释放落点；新笔无终点残影、最终释放坐标、样式即时变化、Esc 后迟到鼠标释放不提交。
- 序号鼠标图像在三个显示缩放级别与实际落下的图元逐像素一致，热点居中，Retina 不重复放大；数字随撤销/重做更新，生成鼠标图像不改变文档/撤销状态。
- 马赛克预览与使用底图准备后的图元逐像素一致；多边形悬停时按实际描边/填充显示下一段，预览不加入文档。序号重叠连续盖章也已验证。
